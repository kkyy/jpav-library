# Phase 4：作品匹配与收藏缺口

扫描与元数据同步成功后，应用在同一数据库事务中按女优重建文件到作品的匹配。只使用当前目录下成功扫描得到的文件名和用户手动修正的番号；不读取视频内容、大小、时间或哈希。自动匹配要求标准番号唯一且作品与该女优有关联。无番号、有歧义、库中无作品的文件不会计入收藏。标题相似不自动匹配。

`movie_matches` 按本地文件 ID 唯一，允许多个文件对应同一作品。扫描范围缩小时，范围外最后一次完整扫描仍有效；完整扫描确认文件消失后才删除匹配。取消、部分失败、离线目录或同步失败时均保留原结果。修改女优目录会立即让旧目录文件不再计入统计，重新扫描成功后清理旧匹配记录。

一位女优的总数为已收录作品关系数。忽略状态存在 `actress_movies` 上，只影响该女优的收藏目标。需收藏 = 总数 − 忽略；已收藏为至少有一个有效本地文件的非忽略作品数；缺少 = 需收藏 − 已收藏；完成度 = 已收藏 ÷ 需收藏。若需收藏为零显示「—」，尚未扫描当前目录显示「待扫描」。多人共享作品只存一条全局作品记录，并可由任一已匹配的当前目录文件满足收藏。

最新作品按来源提供的发行日期排序；日期缺失排在最后。最近同步新增数来自最近一次成功同步，首次同步只建立基线。该新增数表示新收录关联，可能包含历史补录，不等同于新发行数量。来源收录范围可能不完整，因此「缺少」仅相对已收录作品库成立。

匹配状态可在作品库窗口查看和筛选；扫描窗口可看到「已收藏」「作品库不存在」以及同番号多个文件提示。人工修正仍在扫描窗口完成。Phase 5 将完善 Dashboard、封面缓存、全局搜索与排序。
