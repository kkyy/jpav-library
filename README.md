# JPAV Library · 本地作品库

一款面向 Windows 的个人视频收藏管理工具。它整理公开作品元数据，并将作品番号与电脑中已有的视频文件名匹配，帮助查看已收藏、缺少和最新作品。

## 主要功能

- 管理多位女优资料、别名、头像和各自的视频目录。
- 从 S1、IdeaPocket 等公开目录检索作品；也可使用 DMM/FANZA API（需自行配置凭据）或导入 JSON/CSV。
- 扫描所选文件夹及子文件夹，只读取视频文件名并识别番号，不读取视频内容或修改文件。
- 按番号匹配作品与本地文件，支持重复文件提示、手动修正和忽略作品。
- 以封面浏览作品，查看收藏状态、缺少作品、最新作品和收藏完成度。
- 使用本地 SQLite 保存资料，支持备份与恢复。

作品数量取决于已同步的数据来源。来源目录可能不完整，因此“缺少”只表示该作品未在当前目录中匹配到本地文件，不代表女优全部作品的完整清单。

## 使用方法

1. 添加女优，填写名称并选择对应的本地视频文件夹。
2. 同步或导入作品元数据。
3. 扫描本地目录，在作品页查看匹配结果和缺少作品。

## 运行

需要 Python 3.11 或更新版本。在项目目录使用 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e .
.\.venv\Scripts\python -m av_library
```

也可以运行 `run.ps1` 启动程序。可用 `--data-dir "D:\PrivateLibrary"` 指定资料库位置。默认数据库和封面缓存保存在 `%LOCALAPPDATA%\JPAVLibrary`。
